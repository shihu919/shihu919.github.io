# 表白信网页应用 - 需求拆解文档

## 产品概述

- **产品类型**: 浪漫表白信互动网页
- **场景类型**: <scene_type>prototype-app</scene_type>
- **目标用户**: 想要制作浪漫表白信的用户，用于向心仪的人表达心意
- **核心价值**: 以精美的信封动画和翻页效果，呈现一封有温度、有仪式感的电子表白信
- **界面语言**: 中文
- **主题偏好**: user_specified（粉色暖色调、浪漫温馨风格）
- **导航模式**: 无导航（单页沉浸式体验）
- **导航布局**: 无

## 页面结构总览

> **说明**：单页应用，信封封面 + 信纸翻页为同一页面的不同状态切换

**页面文件**: `LoveLetterPage.tsx`

| 区域 | 说明 |
|-----|------|
| 信封封面区 | 初始展示信封外观，含"打开"按钮，点击后触发信封展开动画 |
| 信纸内容区 | 信封展开后显示，含4页信纸内容，支持翻页动画 |
| 音乐控制区 | 悬浮在页面角落，含播放/暂停按钮 + 音量控制滑块 |
| 页码指示器 | 信纸顶部，显示当前页码/总页数 |
| 翻页控制区 | 信纸底部，上一页/下一页按钮 |
| 图片查看弹层 | 点击图片时弹出，放大展示图片 |

## 页面布局建议

- **布局模式**: 单栏居中布局 —— 沉浸式体验，信封和信纸始终居中展示，营造仪式感
- **视觉重心**: 内容 —— 信封和信纸是绝对视觉中心，音乐控制和页码为辅助悬浮元素，不抢占注意力
- **结果承载区**: 信纸内容区；初始态为信封封面（idle 状态），点击打开后进入信纸阅读态
- **移动端适配**: 信封和信纸按比例缩放，翻页按钮在移动端增大点击区域，音乐控制按钮在移动端简化为仅播放/暂停

## 功能列表

- **页面**: 表白信主页
  - **页面目标**: 提供从信封打开到翻页阅读的完整沉浸式表白体验
  - **功能点**:
    - **信封打开动画**: 初始展示信封封面，点击"打开"按钮后，信封从中间向两侧展开，信纸从信封中滑出升起，过渡到阅读状态
    - **3D翻页效果**: 点击上一页/下一页按钮触发3D翻书动画，平滑切换信纸页面，每页内容不超过500字
    - **图文混排展示**: 第2、3页包含图片与文字混排布局，图片有圆角和阴影，文字采用优雅手写体/衬线字体
    - **背景音乐控制**: 页面加载后尝试自动播放，失败则显示播放按钮提示用户手动开启；支持播放/暂停切换 + 音量滑块调节
    - **图片放大查看**: 点击信纸中的图片，弹出全屏遮罩层放大展示图片，点击遮罩或关闭按钮收起
    - **页码与翻页导航**: 信纸顶部显示"第 X 页 / 共 4 页"，底部显示上一页/下一页按钮，首页隐藏上一页、末页隐藏下一页（或置灰）

---

## 状态流转说明

| 状态 | 说明 | 触发转换 |
|------|------|---------|
| `envelope-closed` | 信封关闭，显示封面和"打开"按钮 | 点击"打开" → `envelope-opening` |
| `envelope-opening` | 信封展开动画播放中（约1.5s） | 动画结束 → `letter-reading` |
| `letter-reading` | 信纸阅读态，可翻页浏览4页内容 | 无（持续阅读） |

> 注：翻页操作为 `letter-reading` 状态内的子状态变更（currentPage 变化），不改变整体状态。

## 技术实现要点

- **动画方案**: 信封展开使用 CSS transform + transition（scaleX、translateY），翻页使用 CSS 3D transform（rotateY + perspective）实现翻书效果
- **字体方案**: 使用 Google Fonts 的手写体（如 Dancing Script 或 Ma Shan Zheng 中文手写体）作为标题字体，正文使用优雅衬线字体
- **响应式**: 使用 rem/vw 单位 + media query，信封和信纸在移动端按比例缩小，保证完整显示
- **音乐自动播放策略**: 页面加载时调用 `audio.play()`，catch 失败后显示播放按钮引导用户点击，符合浏览器自动播放策略
- **图片占位**: 使用 picsum.photos 或本地 SVG 占位图，标注替换位置和建议尺寸

# UI 设计指南

## 1. 设计推导依据

- **参考意图**: Free —— 无参考材料，从产品语义与情绪目标出发自主设计
- **核心情绪 / 应用类型**: 浪漫温馨的情书叙事体验 / 互动型单页应用
- **独特记忆点**: 信封从中间向两侧翻开 + 信纸滑出的仪式感动画，配合3D翻页与手写衬线字体，营造拆信读信的私密温柔感

## 2. Art Direction

- **方向名**: 暖粉情书
- **Design Style**: Soft Romantic + Paper Texture —— 以真实纸张与信封质感为核心，柔粉色调传递温暖心动，手写字体强化个人化与真诚感
- **DNA 参数**: 圆角 soft（rounded-lg / rounded-xl）/ 阴影 layered（多层柔和投影模拟纸张厚度）/ 间距 spacious（gap-6 / p-8）/ 字体方向 手写衬线混排 / 装饰手法 纸张纹理、信封封口蜡印、淡金点缀
- **应用类型**: Narrative / Interactive —— 以叙事体验为中心，单场景沉浸式布局

## 3. Color System

**色彩关系**: 玫瑰粉主色 + 同色系浅粉信纸底 + 暖米白信封背景 + 深酒红文字 + 淡金点缀
**配色设计理由**: 玫瑰粉作为主色承载浪漫心动与CTA行动；暖米白与浅粉模拟真实信纸与信封质感，长文阅读舒适不刺眼；深酒红文字保持高对比与优雅气质；淡金用于装饰细节提升精致感。
**主色推导**: 从"表白/情书/浪漫"语义出发，选取玫瑰粉色相（~345°），中等饱和度避免廉价感，中高明度兼顾温柔与可读性；accent 从主色降饱和提明度衍生，border 取暖灰粉保持色调统一。
**使用比例**: 60% 暖米白中性 / 30% 浅粉辅助 / 10% 玫瑰粉 primary；primary 仅用于主按钮、关键高亮与蜡印装饰，不用于文字正文或大面积背景。

| 角色 | CSS 变量 | Tailwind Class | HSL 值 | 设计说明 |
|---|---|---|---|---|
| bg | `--background` | `bg-background` | hsl(30 40% 96%) | 页面背景，暖米白，模拟桌面/衬底 |
| card | `--card` | `bg-card` | hsl(340 60% 97%) | 信纸/卡片底色，极浅粉，带纸张质感 |
| text | `--foreground` | `text-foreground` | hsl(345 35% 20%) | 深酒红棕，正文与标题，优雅高对比 |
| textMuted | `--muted-foreground` | `text-muted-foreground` | hsl(345 20% 45%) | 页码、说明文字，柔和不抢戏 |
| primary | `--primary` | `bg-primary` / `text-primary` | hsl(345 70% 55%) | 玫瑰粉，主按钮、蜡印、心动高亮 |
| primaryForeground | `--primary-foreground` | `text-primary-foreground` | hsl(0 0% 100%) | 主按钮上的文字，纯白清晰 |
| accent | `--accent` | `bg-accent` | hsl(340 60% 92%) | 浅粉，hover/选中底、分页指示 |
| accentForeground | `--accent-foreground` | `text-accent-foreground` | hsl(345 40% 30%) | accent 上的文字与图标 |
| border | `--border` | `border-border` | hsl(340 30% 85%) | 暖粉灰边界，卡片与分隔线 |

**语义色提示**: 成功/确认色 hsl(10 50% 55%)——暖红棕系，三态：bg hsl(10 60% 95%) / border hsl(10 50% 80%) / text hsl(10 45% 35%)；与主色同暖色调，饱和度对齐±10%，避免突兀。无警告/错误强状态色，交互反馈以 primary 与 accent 承接。

## 4. 字体与节奏

- **font-display**: Ma Shan Zheng + Noto Serif SC —— 中文手写毛笔感用于标题与落款，营造亲笔书写的真诚浪漫；衬线字体辅助增强优雅气质
- **font-body**: Noto Serif SC + Lora —— 正文用优雅衬线，长文阅读舒适，符合书信古典感
- **字号**: 信标题 text-3xl ~ text-4xl；正文 text-base ~ text-lg（移动端 text-base）；页码与辅助文字 text-sm。
- **圆角**: 中到大 —— 信封与信纸用 rounded-lg ~ rounded-xl，模拟真实纸张的微圆角；按钮用 rounded-full，柔软亲切。

## 5. 全局布局契约

- **Reference Layout Use**: 按需求结构推导，封面信封 → 4页信纸翻页 → 音乐控制与页码指示
- **Page / Section Order**: 封面（信封）→ 第1页（开头）→ 第2页（回忆+图）→ 第3页（心意+图）→ 第4页（结尾），单页内通过状态切换与翻页动画呈现
- **Standard Content Zone**: Tool / Narrative max-w-md（移动端）~ max-w-2xl（桌面端）+ `mx-auto`，模拟真实信纸宽度，阅读行长舒适
- **Shell / Frame Alignment**: 无传统 chrome，信封/信纸为中心视觉主体，音乐控制与页码悬浮于信纸外上下方，安全区独立网格
- **Padding & Rhythm**: `px-4 md:px-6 py-8 md:py-12`，信纸内边距 `p-6 md:p-10`，保持 8px 倍数节奏
- **Full-bleed Zones**: 信封封面与背景纹理可全宽铺满视口，信纸内容受 Standard Content Zone 约束
- **Local Narrowing**: 信纸正文天然收窄，图片可占满信纸宽度
- **Overflow Strategy**: 信纸内容纵向滚动（单页≤500字基本无需滚动），图片放大查看用 modal + overflow-hidden 锁滚动
- **Flexibility Boundary**: 允许移动端信纸内边距与字号微调；不允许改变主色、纸张质感、翻页动效逻辑与字体系统

## 6. 视觉与动效

- **装饰**: 纸张纹理、信封封口蜡印、淡金细线、干花/花瓣飘落粒子（可选轻量）
- **阴影/边界**: 中 —— 多层柔和阴影模拟纸张厚度与悬浮感，信封有立体投影；边界极细淡粉灰
- **动效**: 精致丰富 —— 信封打开从中间向两侧展开（transform + perspective），信纸从信封中向上滑出；翻页用 3D rotateY 模拟翻书效果；按钮 hover 微放大 + 颜色加深；页面切换 600-800ms 缓动

## 7. 组件原则

- 翻页按钮、音乐控制、图片查看必须有 Default / Hover / Active / Focus / Disabled 状态
- Primary 承担"打开信封""下一页"等主行动；上一页与次要操作用 outline/ghost 样式
- 音乐按钮固定位置，圆形图标按钮，带播放/暂停状态切换动画
- 图片点击放大用 lightbox modal，背景半透明深酒红，支持点击关闭与左右切换
- 加载与空状态延续纸张与手写风格，不用默认骨架屏

## 8. Image Direction

- **Image Role**: 信纸内插图（第2、3页各一张）+ 信封封面装饰图
- **Image Art Direction**: 温柔胶片感 / 暖调柔光 / 生活化场景；构图偏中近景，留有呼吸感；材质模拟胶片颗粒与轻微漏光；情绪为心动、温暖、私密的回忆感。信封封面用蜡印与干花元素的静物特写，信纸内用情侣日常/日落/手牵手等含蓄浪漫场景，避免直白露骨。
- **Image Prompt Keywords**: 暖粉色调、胶片颗粒、柔光、日落窗边、手牵手特写、干花静物、蜡印信封、温柔光影、生活感、低饱和、电影感、中近景
- **Image Avoidance**: 避免影楼风婚纱照、过度磨皮人像、卡通情侣插画、廉价玫瑰花堆素材、高饱和艳粉色、文字水印、AI 素材库拼接感

## 9. Anti-patterns

- **Split personality**: 封面信封一套风格、翻页后又一套；信封、信纸、按钮、音乐控件共享同一暖粉纸张视觉系统。
- **Phantom tokens**: 编造不存在的 CSS 变量；所有颜色与间距从定义的 9 角色 token 与 8px 节奏出发。
- **Default SaaS drift**: 回到默认蓝按钮与纯白卡片；必须用玫瑰粉 + 暖米白纸质感承载整个体验。
- **Invisible interaction**: 翻页按钮、音乐按钮做了 hover 但丢了 focus-visible；每个可交互元素都要有键盘可见的环形或描边状态。
- **Mono-hue tyranny**: 玫瑰粉铺满按钮、图标、边框、文字、背景；按 60-30-10 把 primary 收回到 CTA 与蜡印装饰，其余交给浅粉 accent 与暖米白中性。
- **Heavy animation abuse**: 翻页动画太重太慢或每页都加粒子特效；动效服务仪式感，信封打开与翻页是关键节点，其余保持克制。
- **Unreadable handwriting**: 手写体用于长正文导致阅读困难；手写体仅限标题与落款，正文必须用清晰衬线字体。
